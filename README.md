# AWS VPC Peering Student Demo

This is a static project showcase website for GitHub Pages.

## Publish with GitHub Pages
1. Sign in to GitHub (ask a parent/guardian for help with account setup if needed).
2. Create a **public repository** named `aws-vpc-peering-demo`.
3. Upload `index.html` to the repository root and commit the file.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show the published URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/aws-vpc-peering-demo/`
   Replace the placeholder only with the URL GitHub actually displays.

## Important
This website is a static showcase and contains a simulated test widget. It does not create or test AWS resources. Do not claim real AWS VPC deployment unless you actually create it and collect real evidence. Never publish AWS keys, passwords, OTPs, identity documents, or private key files.
