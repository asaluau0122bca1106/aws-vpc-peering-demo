AWS VPC Peering

Project Overview

Objective

Connect two non-overlapping VPC networks using VPC Peering and test private communication between application instances.

VPC A

10.10.0.0/16

Public bastion subnet and private App-A subnet.

VPC B

10.20.0.0/16

Private App-B subnet, without a public IP.

Required Routes and Security

VPC A private route table

Destination: 10.20.0.0/16

Target: VPC peering connection ID

VPC A public route table

0.0.0.0/0 → Internet Gateway

10.20.0.0/16 → VPC peering connection

VPC B private route table

Destination: 10.10.0.0/16

Target: VPC peering connection ID

Security groups

Allow SSH only from the trusted bastion/current public IP. Allow ICMP Echo Request from the other private host as required for ping testing.

Never open SSH to everyone (0.0.0.0/0).

Important Project Status

This website is a project showcase/demo, not a deployed AWS network. It does not create VPCs, launch EC2 instances, establish peering, or run real ping/SSH tests. To claim the AWS lab is completed, create the resources in your own authorized AWS account and add genuine screenshots, actual resource IDs, and test outputs to your report.
